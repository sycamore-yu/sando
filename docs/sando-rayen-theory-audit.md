# RAYEN 对 SANDO 联合时间与走廊选择的理论帮助

核查日期：2026-09-07。假设读者理解 MIQP/QP、轨迹走廊与反向传播；这里把“满足约束”和“达到最优值”分开。当前目标为仿真研究，保留 SANDO 安全规则，同时评价规划延迟与飞行时间。

**RAYEN 可以把任意网络输出变成指定非空凸集内的点，但不会替网络找出可行的时间和整数走廊组合，也不会自动求出固定组合下最优轨迹。** 它对本项目最有意义的用途，是研究如何快速输出连续可行轨迹；若仍坚持连续轨迹必须由 QP 严格优化，则不能把 RAYEN 当作功能等价的 QP 替换件。

[arXiv 记录](https://arxiv.org/abs/2307.08336)最新版本是 **v2，2026-04-20**。v2 作者为 Jesus Tordesillas、Victor Klemm、Jonathan P. How、Marco Hutter；不要沿用 v1 的三人作者表。本文查阅 [v2 全文](https://arxiv.org/html/2307.08336v2)，特别是 §2–4、§6.2、§7。下述理论讨论不把本地固定参数 API 的局限误称为数学上绝对不允许变化约束。

## 保证的前提与作用

原文处理线性、凸二次、SOC、LMI 约束的交集。§2 假设线性部分和完整集合具有相同仿射包；§3 先降维，再求满足严格不等式的内部点。§4 沿内部点出发的射线限制步长，并映回原空间。这一几何构造使训练和测试输出都在目标集内，与网络权重是否训练好无关。集合必须非空，约束结构有效，且预处理和数值计算正确。[v2 §2–4，Algorithm 1](https://arxiv.org/html/2307.08336v2#S2)

“不要求原空间满维”与“需要内部点”不矛盾：等式会让集合在原空间没有内部，但在正确的仿射子空间中仍可具有内部。退化交集若隐藏了额外等式，必须先正确重表示；不是对空集或任意退化表示都能直接运行。数学保证也不能把浮点容差、错误走廊模型或未编码规则自动包含进去。

RAYEN 前向按网络给出的方向做几何映射，不按目标 \(J\) 迭代寻找最优解。因此对同一个可行集合，差的网络仍可能生成差的轨迹，只是轨迹满足集合约束。这与 QP 根据目标计算 \(x^*\) 的含义不同。“所有可行点可以被表示”也不意味着训练一定找到最优点。

## 输入依赖约束：作者给出条件化扩展，并非完全不支持

v2 §7.1 提出两条路径：保证每个实例有已知内部点、保持凸性和对称性、妥善处理等式；或用隐式优化层在线求内部点。无等式时，作者给出让原点严格可行的参数条件。§7.2 仅讨论已知可微凸集像或星形集合的扩展；§8 仍把一般变化约束应用列为后续工作。[v2 §7–8](https://arxiv.org/html/2307.08336v2#S7)

对 SANDO，关键不在于能否把矩阵写成 \(A(s,t,z)\)，而在于每次都能获得正确的集合及其内部点：

\[
\mathcal C(s,t,z)=\{x:A(s,t,z)x\le b(s,t,z),\ E(s,t,z)x=e(s,t,z)\}.
\]

下面是对本项目的推导，而非原文已实现的结论：

- 若 \(t,z\) 固定后 \(\mathcal C\) 为空，不存在任何映射能输出其中的点。RAYEN 不能消除这个逻辑障碍。
- 若已有可行旧轨迹，它也未必是新走廊、新时间配置下的严格内部点；边界可行与严格内部可行不同。
- 若每次需要优化求内部点、求等式零空间或重新识别退化约束，这部分必须计入在线延迟。不能仅引用预处理完成后的单次射线映射耗时。
- 参数变化时，等式矩阵秩变化、内部点接近边界等情况会影响可微性与数值稳定性。已知单个集合的可行映射，不等于对所有集合参数都有稳定梯度。

作者为无等式情形给出的“原点在所有集合内部”构造可以指导有特殊结构的问题，但不能为了满足它而修改真实 SANDO 走廊。平移到已知严格可行轨迹是另一种可能构造，前提仍是该轨迹确实已知且满足当前完整约束。

## 新增扭矩实验没有解决一般动态走廊

v2 §6.2/Fig. 9 的执行器例子，先用当前关节状态计算原始扭矩，再在扭矩空间限制输出，最后经逆 PD 转回位置命令；其可行集是扭矩 box 与加权球的交集。状态依赖可以通过前后映射体现，这不能直接证明每帧变化的轨迹走廊已有通用实现。[v2 §6.2](https://arxiv.org/html/2307.08336v2#S6.SS2)

对本项目可借鉴的是“找到固定、易表达的安全变量空间”，而不是把扭矩安全保证等同于轨迹碰撞安全保证。两者编码的是不同约束。

## 联合时间与整数选择没有被凸映射自动解决

固定 \(s,t,z\) 时，连续轨迹系数集合可以是凸的；但所有走廊候选对应的是

\[
\bigcup_{z\in\mathcal Z}\mathcal C(s,t,z),
\]

一般不是凸集。让网络同时输出 \((t,z,x)\) 也不会使整数约束和时间耦合变成凸约束。

以下两个数学观察明确了边界：

1. 一个凸集是连通的，可微映射是连续的，连续像也是连通的。因此，原文所述“凸集的可微像”不能用单个这样的映射完整表示分离的多个整数模式；仍需离散分支或其他专门表示。星形集扩展也要求已知星心与有效射线边界，不适用于任意走廊并集。
2. 时间可变会改变轨迹导数尺度和动态障碍约束。某些简单速度约束可以重写成凸形式，但不能据此认定整个联合问题凸。例如归一化多项式中的某个加速度约束可能具有 \(|c|\le a_{\max}t^2\) 的形式，这在 \((c,t)\) 上一般非凸：取 \(a_{\max}=1\)，\((c,t)=(1,1),(9,3)\) 都可行，中点 \((5,2)\) 不可行。是否存在等价凸重参数化必须逐条证明。

因此更准确的结构是：外层学习或搜索 \((t,z)\)，内层在可行的条件集合 \(\mathcal C(s,t,z)\) 中生成/优化 \(x\)。RAYEN 可研究内层连续可行生成，但外层如何选到非空集合仍是独立问题。

## 对当前论文设计的具体意义

| 设计选择 | RAYEN 真正提供什么 | 仍需解决什么 |
| --- | --- | --- |
| 网络预测 \((t,z)\)，硬 QP 求 \(x^*\) | 不能直接替代整数选择或时间可行性检查 | 可行候选、连续优化、失败回退 |
| 网络预测 \((t,z,x)\)，RAYEN 约束连续 \(x\) | 已知非空条件凸集中的硬可行输出 | 当前集合内部点、动态参数化、代价次优性 |
| 固定轨迹安全空间中的连续残差学习 | 若构造完整正确，可对残差加硬约束 | 基础轨迹与集合更新是否覆盖 SANDO 原规则 |

仿真阶段无需先扩展实机实验；但“保留 SANDO 安全规则”应意味着使用同一套原始约束与接受检查。网络或 RAYEN 返回一个数值结果，不能代替检查该轨迹是否满足当前时空走廊、动力学与时间规则。

规划延迟与飞行时间应并列呈现：前者包括约束更新、内部点/降维、网络、RAYEN/QP、检查及回退；后者来自闭环完成任务的实际仿真时间。RAYEN 降低连续生成成本，并不自动缩短飞行时间。若用它替换 QP，还应同时报告原目标差、可行率及闭环成功率，避免把减少优化工作带来的速度优势误认为无代价加速。

## 本地实现核对：约束准备与前向分开

以下为本地 HEAD 的静态源码核对，未修改或运行 RAYEN/SANDO 实现。

- [ConstraintModule 初始化](/home/tong/tongworkspace/refer/rayen/rayen/constraint_module.py:18) 接收已构造的约束集合，将约束、等式零空间和内部点转成缓冲张量。当前 [forward](/home/tong/tongworkspace/refer/rayen/rayen/constraint_module.py:521) 仅接收网络输入，没有逐样本传入新约束的接口；不能假设梯度会自动穿过初始化中的 NumPy/CVXPY 处理。
- [射线前向](/home/tong/tongworkspace/refer/rayen/rayen/constraint_module.py:468) 计算方向、边界距离和截断步长，再映回满足等式的原空间。这里没有最小化 SANDO 轨迹目标的步骤。
- [可行性检查](/home/tong/tongworkspace/refer/rayen/rayen/constraints.py:229) 和 [严格内部点求解](/home/tong/tongworkspace/refer/rayen/rayen/constraints.py:407) 在未提供内部点时调用优化器；默认线性预处理还涉及冗余约束、隐含等式和降维。用户提供内部点可省去相应求解，但该点的有效性仍需保证。
- [耗时脚本](/home/tong/tongworkspace/refer/rayen/examples/scripts/time_analysis.py:27) 在计时前创建集合和层，计时覆盖前向映射。SANDO 若每帧改变集合，必须额外计入准备新集合的成本，再与完整 QP 路径比较。

对于消去等式后的线性约束集合 \(Ay\le b\)，可以直观理解为：从严格内部点 \(y_0\) 沿网络提出的方向前进，到达边界就截断。网络可以决定方向和想走多远，几何层限制实际走多远。这解释了为何任意网络权重可以保持条件可行，也解释了为何它不能在空集里工作。

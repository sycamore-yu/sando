# 共享编码器、顺序条件双头与单提议硬约束执行

2026-09-09。基点 `ce09ee3fc3330014b8247e954b41bd42ad856ba1`（`feat/ampl-gurobi`）。继承 ADR-0001/0002/0004 的信息范围与场景划分，继承 ADR-0006 的在线基线：网络提交决策后，由固定赋值硬 QP 与原约束验收决定是否发布轨迹。本记录只约束第一部分（网络、训练、时间梯度、可重建数据、模型导出）。第二部分（阶段 6–8 耗时归因）预留 ADR-0008，不改本执行链。

## 背景

阶段 5 已有独立时间模型（17 维、三提议、`f∈[1,5]`）和独立完整赋值模型（355 维、每层最多三候选、在线尝试前三个）。在线路径是三时间并行 × 每时间最多三组固定 QP，失败后再做同时间原 MIQP。本轮主链改为一次联合提议：一个连续时间、一个完整赋值、一次硬约束 QP。三提议时间与前三赋值保留为历史对照，不作为本轮主路径。

## 主结构与两个对照

1. **主结构（共享编码器，顺序条件双头）**  
   `h = Eθ(s)`；时间头 `Hφ(h)` 输出有界 `f`；`d0 = max(initial_dt, 2 dc)`，`T = n · d0 · f`（`n=5`，各段等长）；按冻结观察 `s` 和 `T` 生成真实走廊 `C`；赋值头 `Hψ(h, T, C)` 选出一个完整 `z`；固定 `T,C,z` 后求原硬约束 QP。编码器每请求计算一次。走廊平面编码器仍是赋值头内的专用模块。
2. **独立参数顺序对照**  
   现有时间网络与现有赋值网络各保留一份参数，顺序仍是时间 → 真实走廊 → 赋值，但不共享 `θ`。
3. **共享参数直接输出对照**  
   两个头并行读 `h`，赋值头不读 `C`。启用条件是五段×三槽的完整组合编号规则已经明确且可复现。编号规则未落地前只保留接口门槛，不启用该对照。

对外提交一组 `(T, z)`。内部不得把某一时间的走廊当作另一时间的安全问题。

## 参数归属

| 参数 | 主结构 | 独立顺序对照 | 直接输出对照 |
| --- | --- | --- | --- |
| 状态编码器 `θ` | 两头共享同一对象，优化器只登记一次 | 两套独立权重 | 两头共享 |
| 时间头 `φ` | 私有 | 现有时间输出层 | 私有 |
| 赋值头 `ψ` | 私有；评分器输入为原 355 维拼接 64 维 `h`（419 维）。复制原 355 列，新增 64 列先置零 | 原 355 维评分器 | 对固定编号的完整赋值打分 |
| 走廊平面编码器 | 赋值头内复用 | 同左 | 不进入前向（只用于执行链几何校验） |

时间监督损失可更新 `θ,φ`。完整赋值损失可更新 `θ,ψ`。共同训练记录两者对 `θ` 的梯度大小与夹角，先用简单加权。若连续优化辅助项声明“只更新时间头”，则把 `h` 当常量、只更新 `φ`。共享改善性能是待检验假设，关闭共享输入时必须复现原评分器。

## 时间定义

- `f` 为无量纲时长系数。新模型学习范围冻结为 `[1, 2.5]`。原 schema 1 模型继续按 `[1, 5]` 与三个分位点读取。
- `d0 = max(initial_dt, 2 dc)`，`segment_dt = d0 · f`，`T = n · segment_dt`。统一入口为 `sando_time::segmentDuration` 与 `horizonDuration`。
- 第一版保持五段等长和现有线性动力学限幅。改变 `f` 必须同步分段时长、层时刻、障碍预测、最坏时域、基底、导数缩放、恢复系数和轨迹有效期。
- 计划时长 `T`、实际任务时间和计算耗时分列记录。

## 候选身份

完整赋值是五段整数元组，不是逐段独立分类。当前几何由该 `T` 下的生成与编号规则解释；不同时间的同一编号可以对应不同边界。训练标签、在线整数和 QP 统一使用该时间下的编号。走廊消失、重排、数量变化必须有确定的失效处理。直接输出对照在编号规则就绪前不得启用。

## 梯度边界

- 连续时间：固定 `z` 与核验过的几何分支，用原问题最优值对 `f` 的导数；公式只用于通过前向、最优性和局部光滑检查的实例。固定几何与动态完整局部导数分列验收。分支/排序/赋值跳变不是该导数。
- 整数：首轮复用完整代价或好赋值集合；推理硬选择一个 `z`，训练走分类或集合损失。
- 有限差分在新时间完整重建走廊后核对。显式去掉时间惩罚后，须验证原轨迹目标自身产生的非零时间梯度。

## 接受条件与主执行链

```
一个时间 + 一个完整赋值
  → 一次固定赋值硬约束 QP
  → 原约束、数值与时效验收
  → 发布轨迹
```

主提议失败后进入已验收的原时间搜索与原求解器回退。主提议次数与回退次数分别统计。非法时间、空走廊、非法赋值、已证不可行、未决、数值错误、取消、过期与进程故障分开记录。不改变原轨迹目标、终端条件、速度/加速度/加加速度限制、障碍膨胀、未知空间规则和残差容差 `2e-6`。只接受 `GRB_OPTIMAL` 且残差通过的轨迹。AMPL/AMPLS/Gurobi 授权路径保持原样。

## 模型兼容

| 工件 | 旧格式 | 新格式 |
| --- | --- | --- |
| 时间模型 | `schema_version=1`，三提议，`logfactor_bounds=[0,log 5]`，`latent_quantiles=[-1,0,1]` | `schema_version=2`，`output_mode=single`，一提议，`logfactor_bounds=[0,log 2.5]`。旧文件仍由原读取器接受 |
| 赋值模型 | `schema_version=1`，`score1` 输入 355 | 后续共享头为独立版本，`score1` 输入 419；关闭新增列时复现 355 列行为 |
| 规划实例 | `schema_version=1`，固定 `f` 的 QP/MIQP 快照 | 同时间复验仍用此格式 |
| 可重建请求 | 不存在 | 新 `kind=sando_reconstructable_request`，含冻结观察；缺字段时列出真实缺失清单，不伪造地图 |

训练端与在线端对同一输入的归一化时间输出误差门槛 `≤1e-10`。分数近似相等时按预登记稳定排序（分数降序，赋值字典序）。

## 实验与回滚

结构比较限定三组，均使用单时间、单完整赋值、一次主 QP。正式性能由第二部分在隔离资源上测量。旧实验目录只读。新输出根：`docker/dev-workspace/results/joint-time-v2/`。

回滚：卸载 schema 2 时间模型 / 将 `SANDO_CORRIDOR_CANDIDATE_LIMIT` 恢复为 3 / 关闭联合单提议开关后，阶段 5 的三时间×前三赋值路径必须复现。不改采集容器挂载，不把宿主机源码写入 `sando-integer-centered`。

# 允许原目标训练与 RAYEN 评估，保留硬 QP 在线验收基线

2026-09-08 用户要求完成阶段 0–5 的可复现学习闭环，并取消 ADR-0003 对 RAYEN 方法及对照的排除。允许研究无专家标签误差项的原目标训练、RAYEN 可行映射、多模态候选及时间分配学习；以实际约束表示、梯度路径、数据需求和运行结果判断可行性，不预设某种方法胜出。

必需的在线基线仍是“网络选择完整走廊赋值 → 固定赋值硬 QP → 原约束验收”，并公平比较 BC、代价监督和多解集合监督。直接原目标训练中的 jerk 代价沿用 SANDO 实际 QP 的表达式和权重；专家动作/轨迹误差是另一个可选监督项，两者不能混称。RAYEN 或时间学习的实验若改变连续求解职责，必须单列对照与接受条件，不能把可行映射等同于最优求解或声称继承未经验证的安全保证。ADR-0001、0002、0004 的信息范围、安全规则与场景划分仍适用。

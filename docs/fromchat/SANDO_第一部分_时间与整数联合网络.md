## 2. 本轮架构决策

### 2.1 推荐主结构：共享编码器，顺序条件双头

定义：

    h = Eθ(s)
    f = f下限 + (f上限 − f下限) × σ(Hφ(h))
    d0 = max(initial_dt, 2 × dc)
    T = n × d0 × f
    C = 按冻结观察s和时间T生成的真实时空走廊
    z = 赋值头Hψ(h, T, C)选出的一个完整赋值
    x* = 固定T、C、z后的原硬约束二次规划解

s为预测前已经可获得的状态和场景；h为共享特征；E为共同编码器；θ为共享参数；φ为时间头私有参数；ψ为赋值头私有参数；σ为把任意数平滑映射到0至1的函数。T是本次局部轨迹总时长，单位秒；n是段数。

`initial_dt`（初始段时长）和 `dc`（现有时间基准）直接读取原代码语义。计划时长、实际任务时间和计算耗时分别记录。

对外，一个联合策略提交一组(T,z)。内部按“共同编码→时间→真实走廊→赋值”执行。走廊生成属于已有几何模块，编码器每请求计算一次。走廊平面编码可保留为赋值头内的专用模块。

第一版保持五段、各段等长及现有线性动力学限幅模式。学习提议范围建议冻结为f∈[1,2.5]，原模型自身的[1,5]格式保持原读取行为。原求解器回退范围按当前已验收配置保留。新增模型用独立版本记录全部语义。

### 2.2 参数共享的最小落地方式

先复用现有时间模型前两层作为64维状态编码器，再保留其时间输出层。现有走廊平面编码器及完整赋值评分器继续复用。

为完整赋值评分器增加共享特征h的输入。当前355维候选特征与64维h拼接后为419维；建议复制原首层355列权重，新增64列先置零，后续按预定阶段训练。该方法用于保留已有评分能力，实际尺寸以本地源码为准。新权重格式同步扩展线上读取器，旧格式保留回归检查。

同一个编码器参数对象被两个头实际引用，优化器中共享参数只登记一次。复制两份初始相同的权重时，登记为独立参数结构。测试分别回传两项损失，核对共享参数和各私有参数的梯度。

新增列零初始化时，首次赋值损失可能只更新新增列。共享梯度连通测试采用预先构造的非退化权重，并额外检查训练若干步后的真实共享梯度。

先以17维特征完成接线。随后在同一版本化接口加入预测前已存在的少量场景摘要，如已有净空、路径长度或障碍风险字段。记录来源、单位和采集时间。时间头使用预测前信息；赋值头另外使用预测时间对应的真实走廊。

共享参数是否改善性能属于待检验假设。独立参数旧结构作为对照保留。

### 2.3 单次联合直接输出的探索分支

完成推荐主结构的小型验收后，增加一个小规模结构对照：

    h = 共同编码器(s)
    (T, 完整赋值分数) = 两个并行输出头(h)
    z = 从固定编号的完整赋值分数中选出一个整数元组
    C = 按T生成真实走廊
    校验z在当前T和C下的编号与有效掩码
    x* = 固定T、C、z后的原硬约束二次规划解

这个结构中，赋值头只读取预测前共同信息。动态几何构建和合法性检查仍进入真实执行链。

启用条件是候选编号规则已经明确。五段与三个固定候选槽位对应最多243个完整组合；每个槽位由当前时间下确定的生成和编号规则解释。不同时间的同一编号可以对应不同边界，训练标签、在线整数和二次规划统一使用该时间下的编号。旧时间标签转移到新时间时，另做几何身份核查。

走廊消失、重排、数量变化和拓扑变化均有确定的编号与失效处理。该直接输出试验先选一个z，再按重建几何校验；非法z立即触发已登记的失败与回退，主链保持一次提议。相同输入与时间重复生成的编号须一致。真实编号规则尚待建立时，先完成这个接口门槛，再启用直接输出对照。

该分支保留一个完整赋值分类输出。每个类别代表整条五段赋值；硬选择后形成整数元组。连续时间回归与完整赋值分类分别训练。逐段独立分类属于另一个结构实验，留在当前范围之外。

主结构和直接输出结构都只提交一个时间与一个完整赋值，使用同一硬约束接受条件。比较首提议可行率、实际求解次数、回退率、完整请求耗时和任务表现。第二部分进行冻结模型的正式比较。

## 3. 主执行链与安全边界

本轮联合网络的主执行链严格为：

    一个时间＋一个完整赋值
      → 一次固定赋值硬约束二次规划
      → 原约束、数值与时效验收
      → 发布轨迹

主提议失败后进入当前已验收的原时间搜索与原求解器回退。一个主提议与后续回退的次数分别统计。原阶段5的三个时间、前三个赋值模式保留为独立历史对照。

主链保持原轨迹目标、终端条件、速度/加速度/加加速度限制、障碍膨胀、未知空间规则与数值容差。改变T时同步更新分段时长、各层时刻、障碍预测、最坏预测时域、轨迹基底、导数缩放、恢复系数及轨迹有效期。

固定T与z后，求解器只优化连续轨迹变量。每个z均指向该T下的实际走廊，连续求解和最终验收共同使用这一几何身份。

非法时间、空走廊、非法赋值、已证不可行、未决、数值错误、取消、过期与进程故障分开记录。旧轨迹继续执行时，记录其年龄和实际有效范围；持续安全性按已验证条件单独评价。

AMPL（建模系统）、AMPLS（现有求解适配）和Gurobi（求解器）的授权路径保持原样。系统授权、驱动、旧任务和实机操作保持当前状态。

## 4. 梯度与共享参数的明确规则

### 4.1 连续时间的训练路径

固定完整赋值和经过核验的几何分支，用真实原问题计算时间导数。统一写为：

    最小化  1/2 xᵀH(f)x + q(f)ᵀx + c(f)
    满足    E(f)x = b(f)
            G(f)x ≤ r(f)

x是原连续变量；矩阵包括变量界、边界状态、连续性、走廊和动力学限制。变量消元、中心化、缩放与系数恢复的时间依赖一并核查。

只训练最优目标和计划时长时，优先计算最优值导数：

    dJ*/df = 1/2 x*ᵀH′x* + q′ᵀx* + c′
              + νᵀ(E′x* − b′) + λᵀ(G′x* − r′)

ν和λ为按上述约束方向统一的最优乘子；撇号表示对f求导。公式使用范围限定在通过前向、最优性和局部光滑检查的实例。优先复用已安装且验证过的组件；需要时在现有连续求解前向上增加最小的乘子提取与导数接口。

需要轨迹位置或跟踪损失的导数时，再增加最优性方程的隐式反向乘积。固定几何条件导数和完整动态几何局部导数分别登记。动态分支变化、排序变化和赋值变化保留为独立状态。

对新时间完整重建原走廊后，用有限差分核对真实变化。有限差分指小幅增加、减少时间，再重新求解并比较。时间相关特征和矩阵使用保留梯度的计算方式；常量数值快照承担对照作用。

### 4.2 整数分配的训练路径

首轮复用完整代价或好赋值集合进行训练。推理时从分数选择一个完整整数元组；训练时梯度通过分类概率或集合损失更新参数。

局部二次规划时间导数固定z；整数硬选择的跳变通过已有分类训练或后续策略概率训练处理。各类梯度在日志中独立标识。

### 4.3 共享参数的更新范围

共享编码器上线前明确每项损失更新哪些参数：

- 时间监督损失可更新θ与φ。
- 完整赋值损失可更新θ与ψ。
- 两项共同训练时，记录各自对θ的梯度大小及夹角，先采用简单加权和。
- 连续优化辅助项若定义为“只更新时间头”，将共享特征视为常量，更新φ；若允许更新θ，则登记为“共享主干辅助更新”，重新评估赋值分数的变化。

参数共享带来的功能耦合通过上述更新范围和关闭对照检验。先使用现有优化器与简单加权，额外多任务优化器留待实际冲突证据出现。

### 丁：时间与赋值训练

先用同状态多时间数据初始化时间头，初始联合目标采用：

    损失 = 原轨迹目标 / 训练集目标尺度
           + λT × T / 训练集时长尺度

尺度保持有限正值，只用训练数据确定。λT初值建议1，其他取值先在训练/验证配置登记。监督项、原目标项、显式时间项和可行性恢复项分别记录。

训练顺序为：已有赋值模型冻结→训练时间→用新时间下的真实数据训练条件赋值头→共同训练。共享编码器的冻结范围显式记录。

预测时间变化后，以该时间对应的真实模型求目标或标签。旧时间代价表只监督其原条件。不可行和未决样本保留完整记录，连续优化梯度只用于通过有效性检查的项；可行性恢复监督单列。

建议至少16个预登记可训练实例完成100次小批更新，检查保存、恢复、真实梯度和参数变化。通过后按现有训练协议完成3个训练种子。模型选择只使用验证集，同时报告全部请求分母、可行请求分母、有效梯度分母。

### 戊：完整闭环联合训练

前向和环境验收通过后，复用已有PPO（根据采样动作回报更新策略的方法），每步提交一组时间和完整赋值：

    时间从有界分布采样
    按这个时间重建真实走廊
    在对应完整赋值集合上采样一个z
    求解、验收、执行固定短前缀并返回新观察

使用保存的采样时间、走廊和有效掩码计算联合概率：时间概率乘以条件赋值概率。更新时把保存动作视为采样常量，重新计算其概率。空赋值集合定义显式失败转移。

失败提议和回退结果进入同一真实转移；策略更新采用原提议的概率，真实后果归于原提议。记录正常终止、碰撞、时间截断和系统故障。实际执行步长变化时，按持续时间处理折扣和优势估计。

初始回报包含目标进度、实际任务时间、到达、经核验的碰撞、回退、规划失败和跟踪误差。计算墙钟、仿真时间和计划T分别存储，时间成本保持单次归因。

先验证任务回报路径，再加入已通过检查的连续优化辅助项，按第4.3节定义共享参数更新范围。建议至少1000个真实规划转移和10次策略更新，检查两个头及共享参数均按指定规则更新，全部执行轨迹通过原检查。

当前已验收的SANDO仿真可承担最小训练接口。已有其他平台只有在接口验收完成后再复用；本任务主线保持一个环境。

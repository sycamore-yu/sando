1. 最终研究目标 —— 不允许改变
======================================================================

最终思想：

Learning predicts structured planning decisions;
hard optimization preserves explicit feasibility;
trajectory/task costs generated by the optimizer train the learned decisions.

最终训练链：

planning state / scene observation x
        ↓
timing network
        ↓
T
        ↓
hard constrained trajectory QP
        ↓
τ*(x,T,Z)
        ↓
trajectory / task loss
        ↓
implicit differentiation through QP
        ↓
update timing network

对于 Z：

第一阶段继续冻结当前 corridor-cost top-1 policy。

只有最终真实在线 failure attribution 证明：
wrong-Z 是主要瓶颈，

才允许重新启动 Z learning。

最终部署主链必须保持：

Observation
    ↓
predict exactly ONE T
    ↓
rebuild actual C(x,T)
    ↓
predict exactly ONE complete Z
    ↓
solve exactly ONE main hard QP
    ↓
original residual / numerical / freshness checks
    ↓
append trajectory
    ↓
publish
    ↓
controller consumes trajectory
    ↓
UAV executes

即：

1T + 1Z + 1QP

MIQP fallback：

允许作为 safety recovery，
但必须：

- 单独记录；
- 不计入 one-shot success；
- 不允许隐藏第二个 T/Z/QP；
- 不允许为了刷成功率修改 one-shot 定义。

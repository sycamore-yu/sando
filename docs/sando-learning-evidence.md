# SANDO 整数决策学习：监督信号与梯度边界

假设读者已理解 MIQP、固定整数后求 QP，以及神经网络反向传播；不假设熟悉模仿学习或可微优化的条件。本文核对学习设计；本地源码条件由并行源码核对提供，集成状态见主方案文档。检索日期：2026-09-07。

建议先做 **SANDO 数据采集 → 小规模全枚举成本监督/多解监督 → 多候选固定 QP → 闭环补采 → RL 微调**。如果网络只输出硬离散走廊选择，训练并不要求 QP 可微；要利用 QP 的连续梯度，必须明确另一个可微参数入口。

## 1. 把问题和条件写完整

以下是基于用户数学主线的方案定义，实际变量维度与约束以源码为准。设规划输入为 \(s\)，外层时间系数为 \(\alpha\)，走廊集合为 \(\mathcal C\)：

\[
x^*(s,\alpha,z)=\arg\min_x \tfrac12x^TQ(s,\alpha)x+q(s,\alpha)^Tx,
\quad A(s,\alpha)x=b(s,\alpha),\quad G(s,\alpha,z)x\le h(s,\alpha,z).
\]

定义 \(V(s,\alpha,z)=J(x^*)\)；不可行时数学上令 \(V=+\infty\)，训练时另设有限失败损失。固定 \(\alpha\) 后学习的是 \(\pi_\theta(z\mid s,\alpha,\mathcal C)\)。如果继续保留原时间搜索，训练样本必须记录每次时间尝试；否则同一状态在不同时间系数下的不同答案会被误认为标签冲突。

源码核对得到：当前每段要求 \(\sum_pz_{np}\ge1\)，各二元变量只激活对应走廊约束，目标不含 \(z\)，没有额外二元耦合约束。在这些条件下，单选化保持可行轨迹集合和最优值：任意多选可行解中，每段保留任意一个已激活走廊，只会移除约束，原 \(x\) 仍可行；反之每个单选解本来就满足“至少一个”。因此可用类别序列 \(c_1,\ldots,c_N\) 表示 \(z\)，满足 \(\sum_pz_{np}=1\)。原始多热标签须显式投影/展开，不宜在未记录规则时直接逐行取最大值。上述等价性在加入走廊切换惩罚或额外整数约束后要重审。邻段连通只是必要筛选；初末状态、速度、加速度和连续性仍可能使完整序列不可行。

## 3. 监督标签：先保存多个完整解

以下为本方案建议。每个规划实例保存去重后的可行集合 \(\mathcal Z_s=\{z^{(1)},\ldots,z^{(K)}\}\)，以及固定各个 \(z\) 重解 QP 的成本 \(V_k\)。同一时间系数下按实例归一化：

\[
w_k=\frac{\exp[-(V_k-V_{\min})/\tau]}{\sum_j\exp[-(V_j-V_{\min})/\tau]},\qquad
L_{\rm multi}=-\sum_k w_k\log\pi_\theta(z^{(k)}\mid s,\alpha,\mathcal C).
\]

这是把 Neural Diving 的加权多解思想用于 QP 子问题。\(\tau\) 与成本单位一致，宜用训练集尺度归一化。有限解池只代表已发现解，不能解释成全部可行解的精确分布；求解器重复返回同一个解也不应增加它的权重。

多个近似等价走廊存在时，单个最优标签的交叉熵会惩罚其他好答案。另一个选择是对近优集合 \(\mathcal Z_\epsilon\) 使用
\(L_{\rm set}=-\log\sum_{z\in\mathcal Z_\epsilon}\pi_\theta(z\mid s,\alpha,\mathcal C)\)，它鼓励命中任一近优完整解，但不会主动覆盖所有模式。

不要将多个完整序列的逐段平均标签当作可行性保证。例如仅 \((A,A)\)、\((B,B)\) 可行，独立逐段采样仍会生成 \((A,B)\)。首版可保留简单逐段分类，同时用完整序列候选 + QP 筛选；若此问题明显，再使用条件序列模型
\(\pi(z\mid s)=\prod_n\pi(c_n\mid c_{<n},s)\)。走廊 ID 是当前实例的局部索引，输入必须包含几何、有效性掩码及与标签一致的顺序。

采集至少包括：规划初始状态与目标、坐标系和时间戳、完整走廊及时间区间、\(\alpha\)/各段时长、约束和目标配置、\(z\)、\(x\)、目标值、求解状态、耗时、整数最优间隙及界（可获得时）、QP 约束残差。只录执行轨迹无法可靠恢复当时的整数选择和候选集合。

有可行解但达到时间上限的样本可以用作有质量标记的正样本；超时无解、数值失败与已证明不可行必须分开。求解器没找到解不等于证明无解。数据划分按地图/场景/完整飞行回合，避免相邻重规划帧泄漏到测试集。

## 4. 硬离散决策为什么阻断 QP 路径梯度

### 小规模时，直接求离散期望的梯度

这是本方案推断，不是上述论文已经验证的 SANDO 结果。源码核对显示默认 \(N=5,P=3\)，因此在给定状态和时间系数时仅有 \(P^N=243\) 个单选序列。可离线枚举固定 QP，缓存每个候选的有限训练成本 \(C_z\)，再优化

\[
L_{\rm enum}(\theta;s,\alpha)
=\sum_{z\in\{1,\ldots,P\}^{N}}\pi_\theta(z\mid s,\alpha,\mathcal C)\,\operatorname{stopgrad}(C_z),
\qquad
\nabla_\theta L_{\rm enum}=\sum_z C_z\nabla_\theta\pi_\theta(z\mid s,\alpha,\mathcal C).
\]

成本固定且有限时，这是该离散期望的精确梯度，不是对硬选择的替代梯度。无需反传 QP，也无需 RL rollout；与采样策略梯度相比，省去了同一状态内动作采样的方差。它既适用于完整序列 softmax，也适用于逐段概率乘积；后者必须先形成每条完整序列的联合概率再加权求和。

每个 \(\alpha\) 分开枚举。所有可行候选使用固定目标及归一化；已证明不可行者使用预先声明的有限失败成本，超时/数值失败标为未知并重试，不冒充不可行证据。梯度“精确”只针对这套有限成本表：QP 数值误差、有限失败惩罚以及未覆盖状态仍影响实际结果。有限失败成本本身不保证部署策略永不选到不可行序列。

这是值得优先实现的成本监督基线，可直接比较它与多解交叉熵。243 次求解是否经济仍需实测；随 \(N,P\) 增长会指数扩张。全枚举主要放在离线数据生成，线上仍使用少量网络候选及 QP 验证。训练时不能依赖由全枚举获得、线上却拿不到的可行性掩码，否则会隐藏真实部署难度。网络若另外学习连续 QP 参数，缓存成本随参数改变，此公式就不再是完整目标的梯度。

### 单次硬选择的路径梯度

以下为链式法则推论。假设 QP 的所有连续数据由观测给定，网络仅产生 logits，随后硬选 \(z\)：

\[
\theta\rightarrow\text{logits}\rightarrow\arg\max\rightarrow z\rightarrow x^*(z).
\]

固定输入时，\(\arg\max\) 在选择不变的邻域是常数，切换处不连续。因而把 \(x^*\) 换成可微 QP 层，不会使轨迹损失对走廊 logits 获得真实、可用的路径梯度。Straight-through 或软选择只能构造替代梯度，应单独标注为有偏近似。

若原约束用大 M 表达 \(a_p^Tx\le b_p+M(1-z_p)\)，把 \(z\) 放松成概率会允许所有走廊约束同时变松；其解未必位于任何一个原安全走廊。对两条分别安全但绕障不同侧的轨迹取均值，也可能穿过障碍。故软训练后，执行仍须硬选择并重新求解、验证。

确需利用连续梯度时，可另设 \(\eta_\theta(s)\) 输出参考点或受限代价权重，使 QP 数据连续依赖 \(\eta\)：

\[
\frac{dL}{d\theta}\bigg|_z=
\frac{\partial L}{\partial x^*}
\frac{\partial x^*}{\partial\eta}
\frac{\partial\eta_\theta}{\partial\theta}.
\]

这个梯度训练连续头，离散头仍用监督或策略梯度。先保持原走廊及动力学约束；学习时长会改变问题数据和可行性，应单独验证参数化是否保持凸性/DPP。对半正定目标，应检查约束后的解唯一性和 KKT 系统；加 \(\varepsilon I\) 是可测试的正则化改动，会改变原目标，不能当作完全等价。对固定可行实例，在远离活跃约束切换点处用有限差分核对梯度，并同时检查残差。

## 5. RL 可以训练整数选择，无须微分仿真器

根据上表策略梯度公式，对一次规划取 \(z\sim\pi_\theta(\cdot\mid s)\)，固定 \(z\) 解 QP 后得到成本 \(C\)，可优化

\[
\nabla_\theta\mathbb E[C]
=\mathbb E[(C-b(s))\nabla_\theta\log\pi_\theta(z\mid s)],
\]

这里假设成本没有额外的显式参数依赖。若只在独立状态上用 QP 成本打分，这是单步决策问题；只有执行轨迹、观察后续状态并优化累计回报，才利用了 FlightBench 闭环信息。参考成本可包含可行性、规划延迟、任务进度与跟踪效果，但要预先固定单位和权重，并单报碰撞/失败率。

工程上让一个 RL 动作对应一次重规划的走廊序列，环境内部完成 QP、参考轨迹生成和低层跟踪。应保存完整序列的对数概率及当时掩码；QP 不可行时执行备用策略，并给触发失败的原始动作记成本。若每次动作实际是生成候选集再筛选，训练记录须保留这个真实决策过程，不能把筛选后的序列伪装成从原分布直接采样的动作。

这条路径通常适合在监督预训练后微调：初始随机序列可能大量不可行，统一失败奖励很难告诉网络哪一段错了。可用经验证的邻接掩码减少无效探索，但掩码本身不保证完整 QP 可行。

## 6. 闭环补采与最小比较

DAgger 在此处的具体用法是：运行当前“网络 + 固定 QP + 备用策略”，记录实际访问的规划状态；离线在这些状态调用原 SANDO 得到新标签，聚合重训。专家如果失败，保留状态及失败原因，不伪造正确标签。先用确定性数据回放确认 QP 与原问题一致，再进入闭环。

建议比较四个逐步增加能力的版本：原 SANDO；单解监督 + 固定 QP；多解监督 + 多候选 QP；再加闭环补采/RL。可微连续头另作一个消融，避免把整数学习效果和目标改动混在一起。

主指标采用：固定 QP 可行率、首次候选可行率、同实例同时间系数成本差、整条规划链的 p50/p95 延迟与超时率、备用策略占比、任务成功率、碰撞率。标签准确率只作辅助。只有当 MIQP 真正证明最优时，才能将成本差称为对全局最优值的差；否则应报告相对已知最佳解及求解界。

QP 的精确含义始终受数值容差和建模范围限制：它能验证当前模型中的约束，不能单独保证感知误差、未建模动力学或跟踪误差下的真实飞行安全。

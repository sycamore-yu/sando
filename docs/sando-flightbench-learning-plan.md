## 1. 推荐决策

采用 **SANDO 专家问题采集 → 固定走廊 QP 的代价监督 → 策略访问状态上的专家补标 → FlightBench 闭环 RL 微调**。

第一版保持时间系数搜索、走廊生成、连续目标和约束；网络只替代整数搜索。优先解决监督信号，暂不增加连续参数头。硬离散选择不会因为后面接了可微 QP 就自动获得路径梯度；第一版可以通过概率的期望代价获得精确网络梯度。

默认配置 N=5、P=3 时，每个时间系数最多 243 个单选序列。先在少量状态上完整枚举固定序列的 QP，测量离线开销，再决定扩大枚举数据还是只补充有价值的候选。不能在尚未计时前断言枚举更快。

### 整数变量是“至少一个”，不是严格 one-hot

[走廊约束](../../dockerworkplace/sando/src/sando/gurobi_solver.cpp) 的 `createSafeCorridorConstraintsForPolytopeAtleastOne`（约 4037 行）添加：

\[
\sum_p z_{np}\ge1,\quad z_{np}=1\Rightarrow A_{np}c_{nk}(x)\le b_{np},\quad k=0,1,2,3.
\]

空多面体对应变量被固定为零。实际约束调用 `getCP0`–`getCP3`，是 Bézier 控制点；不能仅凭项目存在 MINVO 函数就替换约束基底。

在当前整数变量仅用于这些激活约束、目标不含 z 的条件下，每段单选保留可行轨迹集合与最优目标值：对任一多选可行解，每行保留任意一个激活项只会去掉约束，原轨迹仍可行；单选解又本来就是“至少一个”的解。因此可以令 a_n∈{0,…,P−1}，z_np=1[a_n=p]，学习完整序列 a。

这不意味着原始二进制矩阵是唯一标签，也不意味着所有重新求解的序列都产生同一轨迹。未来若加整数计数、转换或其他逻辑约束，需要重新检查上述等价性。

### 连续问题需固定时间，并核对动力学范数

[优化器](../../dockerworkplace/sando/src/sando/gurobi_solver.cpp) 的 `findDT`（约 4857 行）使用 Δt_n=f·max(initial_dt,2dc)。`setObjective`（3688 行）是 w_j Σ_n ||j_n||²，没有逐段乘 Δt_n。

固定 f 时，Linf/L1 动力学约束为线性，固定 a 后得到 QP；L2 模式存在二次约束，应称凸 QCQP（可适当转成锥规划），不能直接交给仅支持线性约束的 QP 层。默认配置是 Linf，见 [sando.yaml](../../dockerworkplace/sando/config/sando.yaml)。

完整三次系数有 12N 个分量，但默认变量消元使用更少的自由变量 y，再恢复 x=T(f)y+d(s,f)。N=5 时 `createVars` 创建 d3/d4 的三轴分量，共 6 个自由变量。导出数据应区分自由变量与完整系数；不要把 60 维轨迹系数直接误认为 60 个独立变量。

动态走廊也依赖 f：`SANDO::` 相关求解调用在 [sando.cpp](../../dockerworkplace/sando/src/sando/sando.cpp) 约 1240–1321 行为各时间层生成约束。当前走廊时间层计算使用 initial_dt·f，而求解器时间带 max 下界；应记录双方实际时间，检查一致后才接受动态样本。

### 原版外层不是跨时间系数的全局最优搜索

[sando.cpp](../../dockerworkplace/sando/src/sando/sando.cpp) 约 1014–1095 行处理并发求解成功与中止其他候选。第一个收集到的成功结果会触发停止，其选择受到调度影响。应区分“某个 f 下优化成功”和“所有 f 中最小时间/最小目标”。被取消的其他候选不能标为不可行。

初版保留此调度并把 f 作为策略输入。若另行学习 f，须定义跨 f 的任务目标、动态走廊更新和时间代价；只最小化 jerk 会偏好更慢的运动。

## 3. 监督信号：记录优化问题，而不仅是飞行轨迹

一条训练样本对应一个 **规划请求 × 时间系数**。只存位置轨迹或 rosbag 不能可靠恢复求解时的走廊候选、时间层、整数决策和可行性。

| 数据组 | 最少字段 | 用途 |
|---|---|---|
| 身份与时序 | episode/request/factor ID，地图与场景 ID，随机种子，规划起点时间，状态/地图/障碍预测时间戳 | 防止并发串样、过期结果和训练测试泄漏 |
| 可见状态 | 起点 p/v/a，局部终点 p/v/a，局部路径，f、initial_dt、实际各段时间 | 还原边界条件；策略使用部署时可获得的输入 |
| 候选走廊 | 每时间层每候选的 A/b、有效掩码、稳定候选标识、有效时间区间、膨胀参数 | 标签必须绑定实际几何；存原始矩阵用于复算 |
| 优化问题 | 模型快照、变量边界与映射、目标常数/线性/二次项、全部约束、范数、消元模式 | 可靠提取固定 a 的连续问题 |
| 专家结果 | 状态码、是否有解、原始 z、自由变量 y、完整 x、目标值、耗时、约束残差 | 模仿标签及复现检查 |
| 质量信息 | 可用时记录最优界、MIP gap、时限、求解容差、取消原因、后端与代码版本 | 区分已证最优、可行未证最优、未知与不可行 |
| 候选评估 | a、连续求解状态、可用目标、最大违反量、是否可执行 | 训练代价与可行性监督 |
| 闭环结果 | 原建议 a、实际采用 a、回退原因、执行时间、碰撞、进度、跟踪误差 | RL 归因及整体评测 |

现有 AMPL 适配层已有 `ModelSnapshot`、`GRBModel::snapshot()` 和 `RuntimeResult`，见 [ampl_model.hpp](../../dockerworkplace/sando/include/sando/ampl_model.hpp) 约 64–130、286 行。应复用此表示，避免手抄巨量多项式展开公式；但快照本身不包含完整的场景/时间语义，需要在规划请求侧补齐。

当前 `RuntimeResult` 仅有 status/objective/runtime/values，尚无 gap、bound 或 solution pool；[ampls_runtime.cpp](../../dockerworkplace/sando/src/sando/ampls_runtime.cpp) 约 238 行只在 OPTIMAL 时提取变量，`callOptimizer` 约 4976 行也只接受 OPTIMAL。因此这些质量信息是拟新增字段，不能假设已经能导出，更不能直接把原生 Gurobi 的 solution pool 代码粘到适配层使用。

把失败状态分成：已证不可行、超时/取消未定、数值或运行错误。后两类不是不可行标签。无可行候选的状态保留作回退/可行性数据，不强造分类正标签。

## 4. 优先方案：固定序列 QP 给出直接任务监督

定义部署可见的优化输入 u=(s,f,C)，其中 C 为这一请求实际生成的时空走廊。

\[
V(u,a)=\min_y\tfrac12 y^TH(u)y+q(u)^Ty+c(u),\quad G(u,a)y\le h(u,a),\ E(u)y=e(u).
\]

这里 H/q/c 不依赖 a（按当前 SANDO 目标），a 决定保留哪些走廊约束。固定序列问题必须保留全部连续性、边界、地图、动力学和自由变量上下界约束。先以快照替换整数并展开指示约束，再移除整数列；仅把变量上下界设为 0/1 仍不等于已输出标准连续 QP。

### 4.1 最小基线：专家序列模仿

\[
L_{BC}=-\log\pi_\theta(a^E\mid u).
\]

从专家原始多选矩阵选出每行一个激活项，或依据专家曲线四个控制点验证各候选的包含关系。所有标签都绑定本次候选几何，候选 0 没有跨场景固定语义。

为避免惩罚等价好解，可记录经完整固定 QP 验证的近优集合 S_ε(u)，使用：

\[
L_{set}=-\log\sum_{a\in S_\epsilon(u)}\pi_\theta(a\mid u).
\]

集合内必须是完整序列；来自不同轨迹的逐段边缘标签不能任意拼接成可行序列。若仅有一个专家 incumbent，就称“相对专家近优”，不能称全局近优。

### 4.2 更贴近研究目标：枚举候选的期望代价

默认 P^N=3^5=243。实际 P 来自局部路径，不应硬编码；运行时数量更大时使用候选子集，并明确这时不再是全空间精确枚举。

离线对一个 u 的序列分别求解，缓存可行性与 V，训练时使用有限代价 C(u,a)：经确认可行候选使用归一化的优化代价/相对最优遗憾；已证不可行候选使用更高的有限惩罚。归一化规则保存进数据版本，不用 +∞ 参与浮点训练；未知状态重求或另行处理，不能充当不可行项。

\[
L_{cost}(\theta;u)=\sum_{a\in\mathcal A(u)}\pi_\theta(a\mid u)C(u,a),
\quad
\nabla_\theta L_{cost}=\sum_a C(u,a)\nabla_\theta\pi_\theta(a\mid u).
\]

当候选枚举完整、成本已确定且 C 不依赖 θ 时，这是期望代价对策略参数的精确梯度；训练不需要 QP 反向传播或仿真 rollout。它是固定数据分布上的单步决策学习，不是完整飞行任务的 RL。有限不可行惩罚也不是安全证明，推理仍需硬约束求解验证。

第一版可采用每段分类输出、π(a|u)=Π_nπ(a_n|u)，对完整序列联合计算上述损失。若相关多解使单段独立分布出现大量坏组合，再换为自回归序列分布或完整候选打分；两者能表达更丰富的序列相关性。输入需包含走廊几何、时间层、边界状态及有效掩码，平面法向量尺度在网络输入侧统一，保留原始数据用于求解验证。

先训练 BC 基线，随后比较 L_BC+λL_cost 或 L_set+λL_cost。λ、候选数和正负例比例由验证集决定，不预先声称某组权重最优。近优阈值同时设置绝对/相对容差，避免专家目标接近零时的比值失稳。

### 4.3 专家访问分布之外的数据

让当前策略在 FlightBench 内闭环运行，对它访问到的规划状态冻结输入，再查询专家或枚举候选补标，即 DAgger 思路。先离线教师数据后闭环补标，能针对实际偏离状态补齐数据。按地图/场景和整条 episode 划分训练、验证、测试；相邻重规划帧不能随机散到不同集合。

## 5. RL 在何处提供额外价值

当要优化任务成功、到达时间、跟踪误差、回退频率或长期绕行时，QP 的局部 jerk 成本不够，RL 才能提供额外闭环信号。

动作是一次重规划的走廊序列，环境内部完成固定序列求解、有效性检查和轨迹短前缀跟踪，再返回下一次重规划状态。用原有连续控制接口时，轨迹跟踪器负责生成它需要的控制量；不能将 z 直接送入四维控制环境。

\[
r_k=w_p\Delta\mathrm{progress}_k-w_t\Delta t_k-w_e e_{track,k}
-w_f\mathbf1_{QP\ failure}-w_b\mathbf1_{fallback}-w_c\mathbf1_{collision}.
\]

这是待验证的奖励结构，不是已调好的权重。QP 代价可作为额外局部项，但先检查它和时间奖励的竞争关系。用固定重规划周期最简单；周期可变时应按实际持续时间累计奖励并使用相应折扣。

策略梯度形式为 E[A_k∇θ log πθ(a_k|u_k)]，不要求通过 QP 或 FlightBench 求导。PPO 需记录实际采样完整序列的 log-prob，分段分布时求和；不能把 N 段随意当成 N 个独立飞行环境。

回退是环境执行逻辑的一部分：必须同时记录提议动作和执行动作，对不可行提议及回退计成本；不要用回退动作冒充策略采样动作，否则 PPO 概率比会错配。初版在训练中直接采样一个序列，推理可按概率尝试少量候选，分别报告这种差异。

## 6. 真正可微 QP 的适用边界

硬选择 a=argmax πθ 后，对于固定输入与不变 a，原 QP 不再依赖 θ；局部轨迹梯度为零，在切换处通常不可导。可微 QP 层不能修复这条断开的链。

如果研究必须包含 QP 的隐式求导，可后续增加连续头 ηθ(u)，使合法连续参数进入 H/q 或参考轨迹项：

\[
(a,\eta)=\pi_\theta(u),\quad y^*=QP(u,a,\eta),\quad
\nabla_\theta L_{continuous}=\frac{\partial L}{\partial y^*}\frac{\partial y^*}{\partial\eta}\frac{\partial\eta}{\partial\theta}.
\]

离散头仍由 BC/期望代价/策略梯度训练；连续头才使用 QP 梯度。仅学习整个 jerk 目标的共同正比例系数不会改变 argmin，通常没有轨迹学习信号；需影响相对代价或参考项。这样做已改变原始纯整数预测任务，应作为后续独立消融。

先固定硬安全约束和时间，避免把“学习放松走廊”当作安全的参数化。学习时间会改变轨迹基底及动态走廊，不能在冻结旧走廊下声称完整梯度。

隐式求导还需检查解的唯一性、KKT 系统退化与活跃约束切换。在良态样本上做有限差分梯度验证；正则化如改变目标，应记录其数值及影响。

直接软混合多个走廊一般不等价于原走廊并集；大 M 松弛或 Gumbel/直通梯度可作有偏训练近似，但不能据此宣称前向原问题安全或梯度精确。

## 8. 最小实施顺序与验收

1. **基线与采样**：固定 SANDO 版本和完整配置，成功运行一组原版规划；按请求与 f 导出模型/走廊/解。验证重放目标、时间和约束残差，不改成功判定。
2. **固定序列连续求解**：从现有快照提取 QP。用原始完整 z 固定重求，比较目标与可行性；解非唯一时不强求系数逐位相同。对多选 z 的 one-hot 化再求解，目标应不劣于该多选固定问题。
3. **小规模枚举校验**：N=5、P=3 时枚举 243 序列。对已证最优 MIQP，与枚举所得最小可行 QP 目标在容差内一致；如 MIQP 有 gap，则按上下界比较。加入空走廊、时间不一致、不可行、超时及过期结果样本。
4. **监督学习对照**：单标签 BC、多解 BC、BC+期望代价；比较完整序列可行率、代价差距、top-k 成功率、端到端耗时，不把逐段分类准确率当成最终成果。
5. **FlightBench 闭环**：先验证原 SANDO 接入与轨迹跟踪，再替换整数搜索；使用完全相同场景、观测、跟踪器、限制、f 搜索与时限。记录成功率、碰撞率、完成时间、跟踪误差、回退率和总体 p50/p95/p99 规划延迟。
6. **闭环补标与 RL**：只有前述流程可重放、可测量后再加 DAgger/RL。以监督模型为初始化，与不使用 RL 的版本比较。
7. **可选连续头**：明确新增数学目标并检查 QP 梯度；作为独立实验报告，避免混淆整数学习加速与改变轨迹目标的收益。

推理先尝试网络排序的有限个候选 QP；均失败时按原规划器的可用性和实时预算处理回退。旧轨迹只在仍有效时继续执行，动态障碍下不能默认悬停或旧轨迹一定安全。QP 满足的是模型内约束，实际闭环结果还受感知、预测与跟踪误差影响。

性能报告分别给出网络、QP、候选生成、跨进程通信、回退及总耗时，不能只用单次 QP 耗时宣称完整规划加速。

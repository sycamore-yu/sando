# SANDO 整数选择学习：最接近的已有研究

检索日期：2026-09-07。假设读者理解 MIQP、固定整数后求连续子问题、基本监督学习。本文只筛查与当前研究定位直接相关的五篇原始研究，不是系统综述；以下“可能缺口”是待验证的研究问题，不表示新颖性已经成立。

当前方案记为：规划问题参数 \(s\)（包括状态、目标、走廊和时间配置）→ 网络预测整数走廊序列 \(z\) → 固定 \(z\) 求 QP → 连续轨迹 \(x^*\)。将“整数选择”“QP 参数学习”“长期闭环奖励”分开讨论。

## 1. CoCo: Online Mixed-Integer Control via Supervised Learning

Cauligi 等；arXiv 2021，IEEE Robotics and Automation Letters 7(2), 2022, 1447–1454。[原论文](https://arxiv.org/pdf/2107.08143)，[期刊排版稿](https://msl.stanford.edu/papers/cauligi2021.pdf)，[作者代码](https://github.com/StanfordASL/CoCo)。作者代码 README 引用的是 2020 年前身，因此不能假定仓库每处实现都对应 2022 年扩展版。

输入是状态、障碍物等问题参数；输出是逻辑策略，包含整数赋值以及 big-M 约束中可放松的信息。离线解 MICP，构造最优策略类别，用交叉熵训练。在线选 top-k 策略，依次求固定策略后的凸问题，返回可行解或失败；见算法 1、2。实验包含机器人避障规划。

**重合：直接覆盖“预测整数部分 + 连续凸优化”，也覆盖候选重试。** 因而它应当是核心基线。待验证缺口可包括 SANDO 时空走廊的表示、分布变化及闭环代价监督，但换一个规划器本身不构成方法创新。论文数值表现不等于对任意输入都可行，也不是全局最优保证。

## 2. Online Mixed-Integer Optimization in Milliseconds

Bertsimas、Stellato；预印本首发 2019，INFORMS Journal on Computing 34(4), 2022, 2229–2248。[原论文](https://arxiv.org/pdf/1907.02206)，[出版信息](https://pubsonline.informs.org/doi/10.1287/ijoc.2022.1181)。

输入是参数化优化问题的参数，输出是整数赋值与最优处紧约束索引组成的策略。训练信号来自离线求解得到的策略类别。对所研究的 MIQP 结构，预测正确策略后，可以通过等式约束二次问题的 KKT 线性系统恢复解；满足矩阵复用条件时还能预分解。见 §3–5。

**重合：学习离散结构、再精确恢复连续解。** 它比仅固定整数更进一步，还学习连续问题的活跃约束。SANDO 中保留完整 QP 可避免依赖正确活跃集预测，但这是一种实现取舍。不能把文中可复用矩阵的加速无条件套到每帧几何约束都变化的走廊问题。

## 3. Fast Multi-Robot Motion Planning via Imitation Learning of Mixed-Integer Programs

Srinivasan 等；IFAC Modeling, Estimation and Control Conference / IFAC-PapersOnLine 54(20), 2021, 598–604。[作者机构原稿](https://www.merl.com/publications/docs/TR2021-134.pdf)，[出版记录](https://merl.com/publications/TR2021-134)。

输入是机器人初始状态、目标和障碍位置；网络先回归轨迹，然后从预测轨迹确定多数或全部整数变量。监督来自完整 MILP 专家轨迹，损失含轨迹 MSE 和避障、机器人间碰撞惩罚。在线继续解缩减 MILP；若全部整数已固定则成为连续凸问题。见 §3、5、6。

**重合：学习降低整数搜索量，最终轨迹由优化器生成；训练也不只关注标签误差。** 区别是它间接从轨迹导出整数、主要研究多机器人 MILP，用户拟直接预测走廊序列并解 QP。不能据此说“预测后仍由优化器保证约束”是新贡献；同时，预测引出的子问题仍可能不可行。

## 4. Solving Mixed Integer Programs Using Neural Networks

Nair 等；arXiv 首发 2020，本文核查 v3（2021）。这里仅讨论 Neural Diving 部分。[原论文](https://arxiv.org/pdf/2012.13349)，[版本记录](https://arxiv.org/abs/2012.13349)。

输入为 MIP 的变量—约束图，输出整数赋值分布及多个部分赋值；剩余子 MIP 交给 SCIP。§6.1 将可行赋值的目标值定义成能量，不可行为无穷；混合整数情形先固定整数、解最优连续 LP，再计算能量。训练收集求解器发现的多个可行解，以代价决定的权重训练对数似然，不要求每个标签全局最优。

**重合：多解监督、代价加权、固定整数后的连续最优值作为学习依据，都有前例。** 文中并非用户拟议的完整枚举期望 QP 代价损失，也不是无人机闭环 RL。但仅把 LP 换成 QP 或增加多标签，不能直接推出学术新颖性。有限求解样本上的归一化只是目标分布的近似，原文明确说明此边界。

## 5. Learning-Based Hierarchical Approach for Fast Mixed-Integer Optimization

Stefan Clarke、Bartolomeo Stellato；arXiv 2025，2512.03547v1。[原论文全文](https://arxiv.org/html/2512.03547v1)，[版本记录](https://arxiv.org/abs/2512.03547)。本次核查到的是预印本，不声明已被期刊或会议接受。

输入是问题参数；学习上层目标系数，通过较小上层优化决定变量，再将其代入下层约束求解。训练针对最终次优程度构造凸替代损失；不同替代损失利用下层信息的程度不同，不能统称为直接穿过两个硬整数求解器求导。见 §2–3。推理仍需求解上下层问题，未必只剩 QP。

**重合：分层优化、下层解的质量指导上层决策，已有直接研究。** 关键边界是 Assumption 2.1 要求每个允许的上层选择都有下层可行解。SANDO 的任意走廊序列通常不满足此条件。如何处理这种不可行性是可研究的问题，但还需继续检索；其 conformal 次优界也不是无人机碰撞安全证书。

## 对研究定位的约束

以上原论文共同说明：不能把“网络预测整数 + QP”“top-k 尝试”“多解或代价加权训练”单独写成已经成立的新方法。最直接需要复现的是 CoCo 风格交叉熵策略分类，并与所提训练信号使用同一输入、同一候选预算、同一 QP 和同一回退逻辑比较。

以下是由本次对照得到的研究假设，尚未获得文献排他性证明：

- **多解与几何表示：** 走廊编号变化、重叠走廊导致不同整数标签描述相近或相同轨迹集合；能否定义对这些变化稳定、又保留可行性的训练目标？
- **不可行选择的学习：** 当下层 QP 无解时，什么信号能有效改进候选排序，并减少有限在线预算下的失败率？
- **闭环目标错位：** 离线 QP 代价较低是否一定对应较高飞行成功率？若不一致，RL 或闭环补标在哪些条件下优于纯专家模仿？
- **可微路径的必要性：** 如果网络只输出硬整数，须明确使用策略梯度、离散替代梯度或全枚举期望梯度；若还学习连续 QP 参数，则应单独验证该参数头及其梯度是否改善最终结果。

术语上，走廊序列不能未经证明就称为“同伦类别”：不同序列可能属于相同同伦类别，时空约束也不同于静态空间同伦。该关系需由具体走廊构造与轨迹定义证明。本次没有完成 learned-homotopy 子领域的穷尽检索，不应据此声称该方向无人研究。

后续实验应至少记录可行率、原始问题约束残差、相对有界专家解的代价差、包括候选失败和回退在内的总延迟，以及闭环成功率。单纯整数准确率与只统计成功样本的平均求解耗时，均不足以检验上述研究假设。
